우리는 JSON 형태의 단어장 파일을 읽어서, 영어 단어 암기학습을 위한 PWA 기반 "Word Master" 앱을 만들거야. 한글 제복은 "워드 스마트".
React, Tailwind CSS, 그리고 Lucide 아이콘을 기반으로, 직관적으로 사용하기 편하고 화면 공간을 효율적으로 쓰는 모던한 UI 컴포넌트를 디자인해 줘.

### [기본 레이아웃 및 상단 바]
- 상단 바의 좌측은, 앱 아이콘과 로그("Word Master")와 정보제공 'i' 아이콘을 배치
- 상단 바의 우측은, 단어장 관리 등 설정, 파일 열기 아이콘, 구글 로그인을 나타내는 프로필 아이콘 순서로 배치
. 파일 열기 아이콘은 구글 로그인이 된 상태에선느 구글 드라이브 열기, 로그인이 안된 상태는 로컬 파일 열기로 나와.

### [모드 : 학습 모드]
- 학습 모드는 선택한 단어장의 단어들이 일정 숫자만큼 랜덤하게 나오는 단어장 플래시 화면임.
- 상단부터 중앙에 가장 큰 글자로 영어 단어 표시, 그 밑으로 조금 작은 글자로 한글 뜻 표시
- 아래에는 일반적인 텍스트 크기로 영어 예문이 있고, 클릭하면 한글 예문으로 전환
- 하단에는 [학습 완료], [학습 중] 버튼을 배치. 학습 시작전에는 두 버튼 대신에 [학습 시작]버튼만 나올거고.
- 아래쪽에는 게이지 형태로 학습 진행도가 나오면 좋겠고, 다음 단어로 넘어갈 때 카드가 넘어가는 것 같은 화면 효과면 좋겠어.

### [모드 : 테스트 모드]
- 테스트 모드는 일정 숫자의 테스트를 반복하며 영어 단어들이 나오고 한글 뜻을 고르거나 영 단어 스펠링을 입력해야 넘어가는 모드임
- 테스트 결과는 점수로 나타나며, 영단어 기록에 테스트 횟수와 맞은 횟수가 누적되어 관리됨.
- 한글 뜻을 고르는 문제는, 영어 단어 하나에 8개의 한글 뜻이 나오고, 아래 힌트로 영어 예문이 나오며,
- 영어 스펠링을 입력하는 문제는, 한글 의미가 나오고 아래 힌트로 한글 예문이 나옴. 스펠링 개수만큼 빈칸이 나오고, 그중 1자리는 영어글자가 채워져 있음. 틀리면 1글자가 더 채워짐.

### [모드 : PDF 출력 기능]
- 학습지와 시험지를 출력하는 기능으로 PDF 출력 전의 화면을 볼 수 있음.
- 학습지는 단어장에서 선택한 단어들의 목록과 영단어, 한글뜻, 예문이 출력되고
- 시험지는 학습지와 동일한 영단어에 대해서 한글 뜻을 쓰거나, 영단어 스펠링을 맞추는 내용으로 출력

### [단어장 설정]
- 현재 로컬에 저장된 단어장 목록과 선택, 삭제 기능을 제공
- 단어장 별로 제목을 설정할 수 있도록 수정 버튼
- 단어장별 단어 갯수, 학습 횟수, 완료된 단어의 비율을 보여줌

### [모바일 반응형 대응 (Mobile PWA Fallback)]
- PC 보다는 모바일 환경을 중심으로 디자인
- 모바일에서는 하단에서 위로 올라오는 바텀 버튼으로 배치
- PC 브라우저 환경에서는 왼쪽에 네이게이션 바에 메뉴 위치

### [스타일 가이드 (Tone & Manner)]
- 학습에 눈이 피로하지 않도록 차분한 Slate/Zinc 톤의 바탕을 사용하고, 포인트 컬러로는 그린 에메랄드(Emerald)를 사용해 줘.
- 다크모드 완벽 지원(`dark:` 클래스 철저 적용) 및 모바일 터치 최적화(버튼 클릭 영역 여유 있게 확보)를 준수해 줘.
- 단어 공부를 연상시키는 PWA 용 아이콘도 함께 만들어서 제공해줘.

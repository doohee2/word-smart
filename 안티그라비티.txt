우리는 JSON 형태의 단어장 파일을 불러와 오프라인에서도 동작하는 PWA 기반 영단어 학습 앱 'Word Smart (한글명: 워드 스마트)'를 개발할 거야.
내가 첨부한 스티치(Stitch) 기반의 UI 컴포넌트 코드(React + Tailwind CSS + Lucide Icons)를 바탕으로, 아래 마일스톤에 따라 실제 상태(State) 로직과 백엔드 데이터 엔진을 바인딩해 줘.

[기술 스택]
Next.js (App Router), React, TypeScript, Tailwind CSS
인증/DB: NextAuth.js (Google OAuth), Dexie.js (로컬 IndexedDB)
유틸리티: @serwist/next (PWA), jsPDF (PDF 출력), framer-motion (카드 애니메이션용, 필요시 추가)

[Phase 1: 반응형 레이아웃 및 상단/측면 바 라우팅]
반응형 네비게이션: PC 브라우저에서는 좌측 사이드바(Left Navigation)로, 모바일 환경에서는 화면 하단의 바텀 탭(Bottom Navigation)으로 동작하도록 레이아웃을 구현해 줘.
상단 바 로직:
좌측: 로고("Word Master") 및 정보(i) 아이콘 모달 연결.
우측: [설정], [파일 열기], [로그인 프로필].
[파일 열기 분기 로직]: useSession을 확인하여 로그아웃 상태면 브라우저 네이티브 <input type="file" accept=".json" />을 열어 로컬 JSON을 파싱하고, 구글 로그인 상태면 커스텀 구글 드라이브 탐색 모달을 띄워 클라우드에서 JSON 파일을 불러오도록 분기 처리해 줘.

[Phase 2: 로컬 DB (Dexie.js) 및 데이터 스키마]
Dexie.js를 구축하고 JSON 파일에서 파싱한 데이터를 저장해 줘.
word_lists 테이블: id, title, total_words, study_count, completion_rate
words 테이블: id, list_id, word, meaning, example_en, example_ko, is_learned(학습완료 여부), test_count, correct_count
[단어장 설정 연동]: 단어장 목록 조회, 선택, 삭제, 제목 수정 기능을 구현하고, 각 단어장별 갯수/학습횟수/완료비율 통계를 계산해 화면에 뿌려 줘.

[Phase 3: 학습 모드 (플래시 카드 애니메이션)]
선택된 단어장의 단어 배열을 가져와 상단 프로그레스 바(게이지)와 함께 렌더링해 줘.
[텍스트 렌더링]: 영어 단어는 화면 중앙에 가장 크게, 한글 뜻은 그 아래 작게 배치해. 하단의 영어 예문은 클릭(Tap) 시 한글 예문으로 토글 전환(상태 변경)되게 해 줘.
[액션 버튼 및 애니메이션]:
최초에는 [학습 시작] 버튼만 렌더링하고, 시작 후에는 [학습 완료(Done)] / [학습 중(Learning)] 두 버튼을 하단에 고정해 줘.
버튼 클릭 시 현재 단어의 DB 상태(is_learned)를 업데이트하고, 다음 단어로 넘어갈 때 CSS(또는 framer-motion)를 이용해 '카드가 스와이프되어 넘어가는 듯한 트랜지션 효과'를 적용해 줘.

[Phase 4: 테스트 모드 (객관식 & 주관식 게임 로직)]
단어장에서 랜덤으로 단어를 추출해 퀴즈 배열을 생성해 줘. 결과는 test_count, correct_count에 즉시 누적 기록해 줘.
[객관식 모드 - 8지 선다]: 정답 1개 + 로컬 DB 내 여러 랜덤 단어장의 뜻 7개를 섞어 8개의 버튼을 만들어 줘. 상단엔 영단어를 띄우고, 하단 힌트 영역엔 '영어 예문'을 보여줘.
[주관식 모드 - 스펠링 입력]: 상단에 한글 의미, 하단 힌트 영역에 '한글 예문'을 띄워 줘.
정답 영단어의 알파벳 길이만큼 _ _ _ _ 빈칸(Input box)을 렌더링하고, 초기 힌트로 무작위 1개 알파벳만 채워 둬.
사용자가 오답을 제출할 때마다 빈칸 중 1개의 알파벳을 추가로 오픈(힌트 제공)하는 점진적 힌트 로직을 구현해 줘.

[Phase 5: PDF 인쇄 및 미리보기 (jsPDF)]
모달창을 통해 인쇄 전 '미리보기' 화면(HTML 렌더링)을 먼저 제공해 줘.
[학습지 모드]: 영단어, 한글 뜻, 영/한 예문이 모두 온전한 표(Table) 형태로 출력됨.
[시험지 모드]: 영단어 또는 한글 뜻 중 하나가 랜덤하게 빈칸(Underline ______) 처리됨. 영어가 빈칸이면 한글 예문만, 한글이 빈칸이면 영어 예문만 노출되도록 렌더링 조건을 분기해 줘.
[폰트 깨짐 방지]: jsPDF 사용 시 한글이 깨지지 않도록 무료 한글 웹 폰트(나눔고딕 등)를 Base64 VFS(Virtual File System)로 주입한 후 문서를 생성하게 해 줘.

[지시 사항]
기존에 스티치로 작업된 UI 컴포넌트 구조를 먼저 파악하고, Phase 4(스펠링 점진적 힌트 로직) 및 Phase 1(로그인 여부에 따른 파일 열기 분기)에 대한 컴포넌트 설계 접근법을 짧게 브리핑해 줘. 내 승인이 떨어지면 Phase 1부터 코드 작성을 시작해 줘.

[스티치 파일]
스티치 파일은 stitch_design 밑에 있어. 컬러 배색은 DESIGN.md를 참고. 다크모드와 라이트모드 아이콘은 darkmode_icon.png, lightmode_icon.png 의 크기만 줄이고 박스의 모서리만 둥글게 다듬어서 만들어주고, study, test, pdf, setting 폴더에 각각 학습 모드, 테스트 모드, PDF 인쇄 모드 및 단어장 설정 관련 코드와 이미지가 있어. 코드는 반응형으로 디자인되어 있고 이미지는 모바일 screen_mobile.png과 브라우저용 screen.png이 각각 있어. 주로 쓰는 화면은 모바일용이 될 것 같으니 모바일용 화면을 잘 참고해서 만들어줘.
참고로 디자인 파일의 앱 이름은 Word Master 이지만, 실제 개발은 Word Smart 로 만들거야.
